# CPSS LAB 私有完整交付包

## Windows 下载与运行

1. 点击仓库首页绿色 **Code → Download ZIP**（需登录有权限的 GitHub 账号）。
2. 将下载的仓库 ZIP **全部解压**。
3. 打开 `Delivery` 文件夹，双击 `Merge-Download.cmd`。脚本会合并 8 个分卷，并自动验证 SHA-256。
4. 出现 SUCCESS 后，解压生成的 `CPSS-LAB-All-Files.zip`。
5. 打开 `Windows-Ready`，将其中的 `CPSS-LAB-Windows-Textbook-Ready.zip` 全部解压，再运行 `CPSS LAB.exe`。

总包包含教材预置 Windows 版、历史第一版、完整源码、构建说明和用户提供的教材。个人学习进度不在发行包中，保存在本机资料目录。

Windows 包已交叉构建并校验结构，尚未在 Windows 实机运行验证。真实教材已在 Linux 打包应用验证；未逐页人工校对。

网络代理限制大附件上传，因此完整总包以分卷保存于本私有仓库。请保留私有访问权限。
