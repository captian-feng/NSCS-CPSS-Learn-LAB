## Windows 实机验收步骤

1. 干净 Windows 10 与 11 x64，分别测试安装版和便携版；无需预装 Node/Python。
2. 导入自己持有的完整教材，记录耗时、峰值内存和空间；核对真实页数、Part/Chapter/Section 与印刷页码。
3. 核对全部 31 个章首，建立正文、双栏、跨页、表格、图、公式代表页列表；记录明确已验证页和缺项。
4. 三模式浏览、缩放、文字选择、批注 CRUD、原文跳转、搜索；重启后核对保存。
5. 断网后冷启动，再进行新 PDF 导入和全部学习操作。
6. JSON 导出到外部目录；全新 Windows 用户或资料目录恢复；重新导入相同 PDF 后核对引用。
7. 安装升级和卸载后检查资料目录；未完成验证前不要称为发布正式版。

最终产物、归档和结构检查结果见 `docs/delivery.md`；存在文件不等于已通过 Windows 运行验证。
