## 需要继续完成的验收

1. 原书全书：用户上传的 PDF 超过当前 download_file 的 32 MiB 传输限制，不能读取。请使用 7-Zip 把完整 PDF 打成每卷不超过 30 MiB 的分卷压缩包，并上传全部分卷；重组完整原文件后再核验页数、7 Part/31 Chapter/Section 和图表质量。仅拆章节可能丢失原书书签与页标签，不足以替代原文件验收。
2. Windows 实机：解压便携版，首次导入自己持有的原 PDF，检查三模式、批注、重启保留、断网与备份；依据验收矩阵记录实际系统与覆盖页。安装/升级/卸载保留仍待 Windows 验证。
3. 转换质量：复杂表格/公式使用局部保真区域，OCR 未实现；自动阅读顺序、区域边界和字体结构需要在原书上逐项核验，不能保证通用 PDF 无损转换。
4. 扩展功能：题库和双语当前只提供数据结构；题库导入/模拟考试界面、中文导入/语言切换和跨转换修订锚点迁移未实现。
