# 0.3.0 — 原版 PDF 连续阅读

针对 Windows 用户反馈：为导航增加可见中文名称，移除 HTML 重排/对照阅读，修复目录与阅读区重叠，支持自然跨页滚动。进入教材时默认收起功能导航、目录及学习记录，可在顶部独立展开；专注阅读一键收起所有侧栏。

根因修复：PDF.js 的全局 `.sidebar` 样式污染应用同名目录栏。应用改用独立 `library-sidebar`，同时设置明确的网格列、最小宽度与边界，窄窗口允许收起面板。

连续阅读：先读取 1058 页的尺寸元数据，避免不同页比例导致位置漂移；画布仅挂载视口附近页面。目录、页码、搜索、记录跳转、缩放、当前页和阅读位置同步。

验证：16 项单元/集成测试、PDF 桌面 E2E、真实教材 E2E 通过。包含 1024/1280/1600 宽布局、面板开关、跨页滚动、末页跳转、邻近画布数量、PDF 高亮与笔记、全文搜索、备份恢复和重启。真实教材首次就绪约 1.9 秒（当前 Linux 云环境）。Windows 包交叉构建，尚未实机验证。

更新前关闭旧版并导出 JSON 备份；完整解压新版后运行 CPSS LAB.exe。appId 与个人资料目录保持兼容。旧笔记、引用与页码仍保留；旧 HTML 高亮没有 PDF 坐标，保留在学习记录中并支持回到来源页，不伪造原书覆盖位置。

维护源码位于私有仓库的 Source 目录。教材种子与个人资料不得提交为源码。Windows 分卷发行只存入私有仓库。
