# 0.4.0 — 紧凑阅读与章节练习

## 阅读

页码、翻页、比例、缩放、书签、笔记和记录入口合并为紧凑工具栏；默认阅读页顶部两行共约 72 CSS 像素（常见桌面宽度），页脚 25 像素。窄布局自动换行，避免覆盖正文。

功能导航、目录和学习记录边缘支持鼠标拖动调宽，宽度保存到本机设置；分隔条也支持方向键微调。题库列表另有可拖动分隔条。Ctrl＋滚轮只缩放 PDF，比例范围 40%–300%，不改变应用整体字号；点击比例恢复 100%。

## 题库范围和来源

首批 62 道 AI 辅助自编单选题，覆盖本次提供的 31 章，每章包含一个核心知识点和一个重点应用知识点。分类为平台建议的学习优先级，不是官方 CPSS 考试权重；不是官方真题，也不是整本书全部知识点或完整模拟考试。

本次检查教材的文本索引，未发现成套课后选择题；没有使用网上来源不明的考试题。题干和中文逐项解析为本次自编，英文依据摘录来自用户提供的教材。每道题记录章节、页码、来源块/原文摘录。已自动逐题核验摘录确实出现在对应页面，且页面属于相应章节；这不等于独立专家审题或官方认可。

题库只绑定原压缩教材 SHA-256 `01387ea3166a9dd0a7f29c1e4dd468f17a0afc14b4f7fd9786bb294f52256d1d`，其他版本不误套页码。全部离线，不需要模型 API 或网络。

## 练习与资料

章节、优先级、关键词筛选；四选一提交；逐项解释正误；英文原文依据与 PDF 跳转。答错自动进入错题集，重新答对后移入已掌握；所有尝试保留，重启继续可用。

评分在 worker 依据绑定教材与题目判定，不信任客户端的正确性字段。提交编号幂等，避免重试重复写入。历史按答题时间排序，导入旧备份不会使旧错误覆盖较新的正确结果。

复用现有 SQLite answers/practice_sessions 表，保留已有 schemaVersion=1 与 appId/userData，不删除旧笔记或进度。JSON 备份新增可选 practiceAnswers，旧备份默认空数组，可原子合并恢复，冲突时回滚整个恢复。请使用 0.4.0 或更新版本导出/恢复答题记录，旧版备份不包含这些记录。

## 维护

Source/src/practice/bank.json 保存题库。更改题干、正确答案或概念含义时使用新题目 ID，避免错误解释历史答案；仅修订出处或文字也应更新题库 version 并重新执行出处核验。扩展题库时提供四个不重复选项、每项解析、教材版本与准确原文引用。

本次在 Linux Electron 验证 20 项单元/集成测试、真实 Ctrl＋滚轮事件、指针拖动与宽度持久化、连续阅读、62 条引用、答错→错题→重做答对、原文跳转、重启和 JSON 备份恢复。Windows 包交叉构建并检查 ZIP/ASAR，Windows 实机验收仍需用户本机完成。
