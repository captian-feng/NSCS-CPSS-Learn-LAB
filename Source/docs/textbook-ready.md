# 0.2.0 教材预置版

用户最新要求：将上传的压缩教材直接整合为开箱即用软件。此要求替代原来“安装包不含教材”的约束，仅针对本次单独制作的预置发行包。没有向公开仓库或外部 CI 上传教材。

## 输入核对

- 文件：`（已压缩）NSCA's Essentials of Sport Science.pdf`。
- 大小：13,131,026 字节，约 12.5 MiB，低于附件下载工具上限，已实际下载读取。
- SHA-256：`01387ea3166a9dd0a7f29c1e4dd468f17a0afc14b4f7fd9786bb294f52256d1d`。
- 实际 1,058 页（不是原先描述的 1,057 页），未加密。
- 195 个实际 PDF 书签，含 7 Part 和 31 Chapter，保留来源页码及层级。
- 正文可提取，图像包含 JPEG2000。没有原始未压缩版本，不能比较压缩前后的清晰度。

## 本次修复

1. 给 Node PDF.js 配置随包分发的本地 WASM 路径，修复 JPEG2000 图片解码缺失。增加自建 JPX 图像回归测试。
2. 当多行正文跨过页中央时，避免把粗体/斜体切分出的片段误判为双栏；栏区间不再静默丢弃临近标题的文本片段。
3. 仅把实际绘制路径当作矢量图，排除纯裁剪路径，避免每页插入一张虚假的整页图像。
4. 保留正文区域的小型公式图像，过滤页脚小图和近乎整页的背景。封面仍可用原书模式完整查看。

## 开箱即用机制

全书转换在构建时完成。发行包携带 `resources/bundled-library/manifest.json`、只读种子 SQLite、原 PDF 和转换报告；字体/CMaps/WASM/worker 全部本地提供。

首次启动：验证清单、数据库和 PDF 摘要 → 验证种子不含个人记录 → 把 PDF 复制到 userData → 在事务中合并教材内容与检索索引 → 仅在没有阅读记录时定位第 1 章（PDF 第 53 页）。

不覆盖整个用户数据库，不替换已就绪教材的块 ID，不覆盖已有笔记、书签、章节状态、阅读位置、主题或最后阅读教材。后续启动检查安装标记，避免重复转换或重复安装。损坏的预置资料显示明确错误，仍保留用户原资料和手动导入能力。

预置数据库采用 DELETE journal 模式封存，无 WAL/SHM 依赖，支持从只读发行资源初始化。个人资料继续使用 WAL 的独立本机数据库。

## 测试范围与限制

本次实际结果：

- 完整导入 1,058 页，构建时处理用时约 17.54 秒（当前 Linux 机器实测，不是 Windows 性能保证）。
- 8,334 个结构块；302 个 HTML 图文/公式区域；195 个目录节点。
- 31 个章首与原 PDF 独立提取结果自动比对通过；31 个章首又通过桌面 API 检查标题。
- 所有参考文本超过 100 个非空白字符的页面，转换后字符数量均不低于独立提取量的 98%。数量覆盖不证明文字顺序或语义正确。
- 对照独立 PDF 引擎检测到的 247 个非页脚、非整页背景的图像实例，均在 HTML 区域中找到至少 80% 面积覆盖；不代表图片质量逐张人工核验。
- JPEG2000 解码警告为零。5 个无可提取文本页为 PDF 第 1、142、358、571、1058 页，保留原书图像查看。
- 手工查看了第 53 页的 HTML 章首与正文，以及第 31 页的实际科学示意图；没有逐页人工检查 1,058 页。
- 16 项单元/集成测试通过；通用桌面 E2E 与真实教材预置 E2E 通过。真实教材测试首次可阅读用时约 1.36 秒（当前 Linux 开发运行方式），验证无需导入、三模式、真实搜索、图像渲染、笔记和重启后位置保留。
- 使用实际含教材的 Linux ASAR 发行目录再次执行真实教材 E2E，通过；新资料目录首次可阅读约 1.44 秒，已有笔记与 PDF 第 31 页阅读位置在重启后保留。此测试读取真实 resources/bundled-library，而非开发环境的种子路径。
- Windows x64 ZIP 构建成功，大小 198,574,756 字节（约 189.4 MiB）。CRC、x64 PE 头、0.2.0 ASAR 与生产构建一致性、教材和 SQLite 摘要、1058 页/195 目录节点均检查通过，预置数据中个人记录/进度/位置/偏好均为零。

全书处理、独立提取器的字符数量覆盖比对、全部章首自动比对，以及实际桌面启动/阅读/搜索/图片渲染/批注/重启测试均有独立记录，见本目录中的验收记录。自动覆盖检查不能证明语义顺序、科学公式和所有图表均逐页正确；复杂页请使用原书或对照模式核验。

此版本没有新增中文译文或官方题库。Windows 包仍在 Linux 交叉构建，未在 Windows 10/11 实机运行。完整解压后双击 EXE；不要单独移动 EXE 或删除 resources 文件夹。

## 本次交付文件

- `release/textbook/CPSS-LAB-Windows-Textbook-Ready.zip`：含本次用户上传教材的 Windows x64 预置便携包。
- `release/textbook/CPSS-LAB-Source-0.2.0.zip`：更新源码、依赖锁文件、构建配置、测试和说明；不包含教材和预置数据库。
- `release/textbook/SHA256SUMS.txt`：最终文件 SHA-256 校验值。

解压到一个完整的新文件夹后双击 `CPSS LAB.exe`。第一次使用自动打开第 1 章；有历史学习资料时保留最后阅读位置和偏好。运行不需要联网或远程服务。建议保留旧版目录作为回退，更新时不要手动删除本机资料目录。

## 构建与私有资源

- 准备：`npm run build`，然后 `node out/main/prepareBook.js <PDF> .local/textbook-ready`。
- 真实教材测试：`npm run test:textbook`；可设置 CPSS_TEXTBOOK_EXECUTABLE 指向打包后的程序复测。
- Windows：`npm run dist:win:textbook`。种子缺失时应先执行准备命令。
- 源码归档可以通过 CPSS_SOURCE_ARCHIVE 指定新文件名；始终排除 PDF、SQLite、.local、release 和 node_modules。

预置包属于含本次上传教材的专项包；通用包和源码归档仍保持无教材。后续模型不可把 .local/textbook-ready 加入版本控制。
