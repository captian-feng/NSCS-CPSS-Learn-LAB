# 0.5.0 — 桌面批注交互与新版 CPSS 覆盖题库

## 阅读交互

参考 Zotero 的桌面阅读逻辑，保留自己的实现：教材标签页、目录/批注切换、批注按颜色筛选及按页码/修改时间排序，点击左侧批注或PDF高亮时定位原页与原文区域，并在右侧编辑笔记。离开编辑框自动保存，也可手动保存。切换教材保留已展开的面板布局，并隔离异步保存与当前教材展示，避免旧书刷新污染新书。

保留紧凑工具栏、连续滚动、Ctrl＋滚轮缩放和可拖动侧栏；Ctrl＋F进入原文搜索，Ctrl＋Shift＋A打开批注栏。未引入 Zotero 代码或依赖，配色改为中性的桌面界面与蓝色强调。

## 题库与官方框架

已核对2026年7月1日生效的CPSS DCO，按运动科学理论与过程、跨学科需求分析、评估与监控、数据管理四领域的24项任务建立映射。官方计分题领域分布为24/25/29/22，总计100。官方考试说明还区分运动员案例、研究评读和独立题；本库不宣称为官方格式的完整模拟考试。

参考CSCS公开考试说明中的基础知识与实践应用组织方式，没有复制或改写商业题库、官方案例原题或其答案。当前215道自编题，含188个独立条目和9组原创案例的27个子题：6组运动员案例、3组研究评读。全部31章均至少6题。题型为44基础、25计算、116案例、30研究判断。

新增任务、领域、题型筛选和大纲覆盖表。覆盖表显示每项任务的题量和已作答数，允许直接跳到对应筛选；官方大纲通过固定可信域名链接在外部浏览器打开。任务标题为中文概括，映射与学习优先级均由本平台整理，不是官方考试权重或背书。

计算涉及session-RPE、负荷变化、标准分、变异系数、速度/加速度、冲量、相对力量、目标心率、发生率、分类准确率、睡眠效率及营养补液等。案例数据均为教学构造，不是临床处方或实际运动员资料。

## 依据、覆盖边界与兼容

教材哈希继续绑定原压缩教材。每题有英文原文摘录、页码和自编逐项解析；原文是相关依据与背景，不声称计算或案例答案在原书逐字出现。215条引用已自动核验存在于对应章节。任务有映射不等于穷尽每个任务的全部知识、完成专家审校或预测真题。深度差异和后续缺口见 coverage-0.5.0.md。

原0.4的62题ID、正确选项位置及选项解释保持兼容，有回归测试保护。数据库格式、appId和个人资料目录不变，旧笔记、答题和错题记录继续保留。

## 验证

22项单元/集成测试、2项桌面E2E及真实教材E2E：目录/批注切换、侧边编辑保存、批注到PDF定位、双教材异步保存隔离、原有阅读/备份/错题功能、全部215条引用、24项任务覆盖、案例表格和筛选、定量题答案与旧题兼容。Windows包交叉构建后检查ZIP、教材哈希、代码字节一致性；Windows实机执行仍需用户本机验收。
