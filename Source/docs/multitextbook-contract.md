# 多教材与题库数据接口草案

基线为 CPSS LAB 0.5.0，源代码快照对应提交 `0d325b2748a94efb871fb8249155eb16307e445e`。此文件约定后续实现的行为，实际接口以完成迁移和测试后的实现为准。

## 身份与关联

- 教材文件的 `bookId` 继续使用现有 PDF SHA-256。重复导入相同文件复用该身份。不同 PDF 的关联须由用户确认。
- `bankId` 在所有题库内唯一，`questionId` 在所属题库内唯一，题目修订使用不可变的 `revisionId`。历史答题关联三者与 `bookId`。
- 一份题库可显式关联多个教材文件版本。每条来源固定引用一个 `bookId`、零基 PDF 页索引、页面标签和原文引用。书面页码和 PDF 索引分开保存。
- 旧 CPSS 题库和旧题 ID 保持稳定，既有题目正确答案与选项语义保持一致。旧备份没有修订信息时，按内置兼容版本处理。
- 不同题库使用相同 `questionId` 时必须以题库 ID 加题目 ID 查询，防止串题。

## 题库导入格式

第一版采用版本化 JSON。顶层含 `format`、`schemaVersion`、`bank` 和 `questions`。`format` 固定为 `cpss-lab-question-bank`，初始版本为 1。`bank` 包含 `id`、`title`、`version` 和关联的教材文件 ID。`questions` 包含稳定 ID、修订 ID、状态、题干、选项、正确选项 ID、选项解析、章节、知识点和来源数组。

每道单选题使用稳定的选项 ID 保存正确答案，选项显示顺序的调整不能改变旧记录含义。导入时验证必填字段、ID 唯一性、选项有效性、来源所属教材和 PDF 页范围。未关联的教材需要用户明确处理。对于同 ID 不同内容，显示冲突并要求明确选择，导入以事务提交。

## 生命周期和历史

题目具有草稿、待审、已发布和已停用状态。生成内容先保存为草稿。用户审核后发布，正式练习选择已发布修订。

题干、选项或答案的语义发生变化时建立新修订。作答保存所使用的题目修订、选项、判分结果及足以复核的快照。原有作答不可随题目修改而改变。练习重试使用幂等提交 ID，重复提交的参数不一致时返回冲突。

## 生成任务

生成任务记录教材文件 ID、章节范围、输入文本与定位信息、模型版本、参数、批次、状态、结果草稿和失败原因。重启后未完成任务处于暂停状态，可恢复已提交检查点。取消和重试不重复创建已提交结果。

引用必须经过页面与原文匹配校验，机器校验结果和人工审校状态分别记录。空文本页与无法定位来源的生成项需要标记和处理。模型输出只作为待校验数据。

## 迁移与备份

迁移前建立一致性备份，在事务中创建新结构并迁移数据。迁移失败保留可恢复的旧数据与错误信息。恢复必须覆盖题库、修订、草稿、来源、作答、学习记录及生成检查点，旧 JSON 备份的缺省字段依据兼容规则补齐。恢复中的 ID 冲突不能静默覆盖已有内容。

## 安全边界

文件选择经过主进程原生对话框。renderer 只调用明确允许的方法，参数在 worker 端验证。本地模型接口限制到本机并校验请求，教材文本和模型输出不能取得文件系统执行权限。
