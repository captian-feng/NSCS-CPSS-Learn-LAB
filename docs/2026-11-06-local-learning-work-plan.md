# 本地多教材学习工作台实施与任务分派

后续执行请优先阅读同目录 `AGENT_EXECUTION_HANDOFF.md`，其中记录了本轮开发后的实际状态、角色任务和验收标准。本文保留最初规划背景。

日期为 2026-11-06。本文件用于下一轮向子智能体分派任务。当前交付为实施计划。

## 1. 用户目标与完成定义

在现有 CPSS LAB 上扩展多教材学习。用户可以先安装通用功能，以后导入自己的教材，按书或章节建立题库、知识卡片和学习任务。应用、教材处理、模型推理和学习数据均在本机运行与存储，功能完善后再单独规划云端发布。

目标使用流程为「导入教材 → 查看解析结果与目录 → 选择章节与学习目标 → 本地生成草稿 → 查看原文并审校 → 加入题库或卡片 → 练习与复习 → 本地备份」。已有题库支持直接导入。

新教材可以驱动内容与配置生成。全新的交互工具，例如专项计算器或模拟实验，需要后续开发、测试和版本发布。

第一轮开发采用自制中英文 PDF 和扫描样本。真实第二本教材作为后续适配验证材料，通用功能开发可立即开展。

主要依据为仓库中的 `Source/docs/architecture.md`、`ipc-contracts.md`、`data-model.md`、`Source/package.json`、练习引擎、存储实现与现有测试。部分文档描述较早，开发时用代码和实测校正文档。

## 3. 实施约定

1. 延续现有桌面架构，优先复用阅读器、锚点、导入断点、SQLite 和 IPC 验证。
2. 题库、个人学习记录、教材文件分别拥有清晰的存储与导出边界。用户可从一本书开始使用，课程分组按需启用。
3. 首个完整版本以单选题和知识卡片完成自动生成闭环。多选题、简答判分和复杂学科工具列入后续扩展。
4. 内容状态采用草稿、待审、已发布和已停用。只有已发布题目进入正式练习统计。
5. 模型与 OCR 资源在首次准备时获取或本地导入，运行阶段支持断网。安装说明明确所需资源、空间与实测硬件。
6. 题目来源保存教材版本、PDF 页索引、书面页码、原文片段与锚点。模型输出的依据须经过程序校验和人工审阅。
7. 答题记录绑定题目修订版，并保存判分所需的题目与答案快照。题目改版后仍可解释旧作答。
8. 数据库变更包含版本化迁移、可恢复备份和失败处理。测试运行使用独立资料目录。

### P01 数据与接口设计

- 定义教材实体、教材文件版本、章节、可选课程分组、题库、题目修订、来源引用、作答、生成任务与审校状态。

- 明确题号命名空间、题目版本与题库版本的区别，规定重复导入、冲突合并、停用和恢复语义。
- 约定题库 JSON 格式及版本，提供合法样例、冲突样例和错误样例。界面页码采用用户可理解的编号，存储页索引与原文页码标签分开定义。
- 定义模型输入输出、草稿结构、审校动作、任务进度和取消行为。定义对应 IPC 方法与错误结构。
- 验收条件为 B、C、D 可以用同一套样例分别开发，公共字段与失败语义都有明确解释。

### P02 数据模型与旧资料迁移

- 主要改动范围为 `Source/src/storage/`、`Source/src/shared/types.ts` 和必要的存储测试。

### P03 通用教材导入与章节管理

- 主要改动范围为 `Source/src/importer/`、`Source/src/domain/anchors.ts` 和导入相关服务。
- 导入流程收集或编辑书名、作者、语言和版次，区分导入中、可阅读、解析完成和需要处理。
- 支持中英文可选文字 PDF，检查中文检索与断词效果，按需要调整索引策略。
- 优先使用 PDF 目录，提供推断目录、页码范围导航和手动校正。用户能够设置某章的起止页。
- 识别空文本页、扫描页、加密文件和损坏文件，报告页级问题。导入可以暂停、恢复和重试。
- 同一文件重复导入复用现有记录，新版本文件经用户确认关联到同一教材。
- 验收采用英文、中文、双栏、缺目录和重复文件样本，核对搜索结果、批注与原文跳转。

### P04 本地 OCR 与复杂页处理

- 检查本机资源后选定一种可交付的本地 OCR 方案，验证中文、英文及 CPU 运行路径，记录依赖与模型许可。
- 对扫描页或文字不足页运行 OCR，保留原始 PDF、识别文本、页面坐标和识别问题标记。
- 支持按页重试、暂停恢复和人工校正，校正后更新索引并标记受影响的生成草稿。
- 对表格、公式、图示页提供原页或局部图像核对入口。生成流程可跳过缺乏可靠文字依据的内容，并说明跳过范围。
- 重处理时保护已有记录的锚点，存在歧义时交由用户重新关联。
- 验收覆盖纯扫描、文字与扫描混合、旋转页及低清晰度页，确认断网处理和错误恢复。

### P05 题库导入、编辑与版本管理

- 主要改动范围为 `Source/src/practice/` 的数据访问与校验，以及新增题库管理模块。
- 从数据库按教材与题库读取题目，CPSS 题库通过同一路径加载。
- 支持 JSON 预览、字段验证、题目去重、教材关联、冲突处理和原子导入。导入内容按草稿或已审校来源记录。
- 编辑题干、选项、正确答案、逐项解析、知识点、难度与来源。单选题支持明确范围内的可变选项数。
- 更新答案、选项顺序或题意时创建题目修订版，旧作答使用原修订版判读。题库更新采用可预览的增量操作。
- 对错题状态的跨修订继承制定规则，题意改变时用待重测状态表达。
- 验收覆盖两个题库题号重名、同包重复导入、局部数据错误、题目停用、版本回退和历史答案查询。

### P06 通用练习与教材管理界面

- 主要改动范围为 `Source/src/renderer/App.tsx`、`Practice.tsx` 和相关样式，公共 UI 由 C 统一整合。
- 教材切换后展示对应题库、题目和作答状态。提供题库选择、导入入口和题库管理入口。
- 将章数、领域、任务和考试说明从固定 CPSS 文案改为题库配置。普通教材按章节和知识点组织。
- 保留原文跳转、逐项解析、错题重做与历史记录，进度统计区分未答、答对、错题及待重测。
- 发布、答题和切书并发时防止显示过期异步结果，加载失败提供可操作的恢复入口。
- 验收从真实界面执行两本教材的切换、练习和重启恢复，并检查 CPSS 原流程。

### P07 本地模型运行与设置

- D 负责检测 CPU、内存、GPU、显存和可用磁盘，结合实际机器选择并验证一种本地运行后端和一个适用模型。
- 明确资源安装、离线文件导入、版本记录、首次加载和卸载方式，报告下载大小与空间需求。
- 用 CPU 或已验证的 GPU 路径完成真实章节推理，记录时间、峰值资源占用和输出质量，依据结果设置上下文与批量上限。
- 本地推理服务默认绑定本机，若存在 HTTP 接口则限制访问来源并按需要设置本地认证。
- 设置页能够显示已安装模型、运行状态、内存不足、服务未启动及输出异常，并支持重试和取消。
- 教材文本作为数据处理，模型输出严格通过结构校验，工具调用和文件执行保持明确边界。
- 验收需要一次断网真实推理，模拟输出仅用于开发测试。若硬件无法承载目标模型，报告实测并调整模型或批量后继续验证。

### P08 按章节生成任务

- 将选定章节按来源锚点切成适合模型处理的片段，保存原文坐标、解析版本和内容摘要，便于定位和重复检查。
- 用户设置范围、数量、语言和难度，从原文生成单选题、解析、来源引用及知识卡片草稿。
- 每题检查结构、正确选项、选项重复、引用文本能否在来源中定位、页码有效性及近似重复。
- 分开呈现程序校验结果与内容正确性审阅。数字题需要核对计算、单位和条件，来源不足的题目保留失败说明。
- 任务保存进度、已完成批次、模型版本和生成参数，支持取消、重启恢复、失败批次重试，避免重复写入。
- 记录已处理、跳过和失败的章节范围，生成统计使用实际完成数量。
- 验收覆盖真实模型任务、无效输出、断连、取消、程序重启、重复重试及含有干扰指令的教材片段。

### P09 内容审校与发布

- 界面并排呈现草稿、原文引用和对应 PDF 页面，支持编辑、批准、驳回和重新生成。
- 发布时再次验证题目与来源，使用事务处理整批发布，内容变动后旧批准状态重新进入待审。
- 保存审校状态与修订记录，明确模型检查通过和用户确认的区别。
- 题库页展示来源教材版本、生成批次与审校状态。失效来源能够重新关联或停用。
- 验收包括错误页码、原文不支持答案、干扰选项有争议、草稿批准后再修改及发布中断。

### P10 卡片、复习与学科配置

- 将已审校知识点或题目转换为现有卡片记录，卡片保留原文跳转和生成来源。
- 复用现有任务、日期和重点管理，增加按教材或题库过滤，支持从错题创建复习任务。
- 以学习进度和实际作答形成仪表盘，对模型建议的重要程度与实际学习表现分别展示。
- 将 CPSS 大纲封装为可选课程配置，其他教材可使用章节与知识点配置。大纲映射状态能够人工修改。
- 验收覆盖卡片编辑、复习完成、任务跨教材隔离和普通教材缺少考试大纲的正常使用。

### P11 完整备份与恢复

- 扩展备份内容，覆盖教材元数据、题库及修订版、来源、草稿、审校、作答、笔记、任务、生成检查点和配置。
- 提供学习数据备份，以及可选择包含教材的完整书库备份。模型权重采用独立管理并随清单记录，避免无意复制大文件。
- SQLite 采用在线一致性备份方法或关闭数据库后的完整备份，资源文件与数据库引用保持一致。
- 恢复前验证版本、大小、文件路径与内容摘要，恢复采取事务或可回退的分阶段流程。
- 兼容旧 JSON，缺失教材可重新关联。恢复的运行任务转为暂停，供用户继续处理。
- 验收覆盖跨目录或模拟另一台机器恢复、重复恢复、缺文件、损坏包、版本冲突与途中失败。

### P12 集成、回归与离线验收

- 所有工作包随代码提交必要的针对性测试，A 集成后统一运行类型检查、单元测试、构建和相关 E2E。
- 自制样本覆盖中文、英文、扫描、混合、双栏、目录缺失、同书不同版本、题号重复及旧备份。
- 以两本测试教材验证从导入到审校、练习、复习、备份恢复的完整流程。来源页码、答案和解析进行人工抽查并记录样本范围。
- 断网验证阅读、OCR、推理、审校、练习与恢复，检查应用外连行为和本地服务绑定。
- 大文档、连续生成、内存不足、应用异常退出、重复操作和多任务切换应有可恢复的状态。
- 保持生成期间阅读界面可操作，依据目标机器实测设定批量限制与性能标准。
- 对 CPSS 旧数据执行迁移、题号与正确选项兼容、批注定位、备份恢复回归。
- 交付实测环境、执行命令、通过结果、已知限制和缺陷清单。关键数据丢失、串书、错判和无法启动问题修复后再交付。

- 使用说明包含「新教材首次导入」「已有题库导入」「按章生成与审校」「失败恢复」四个完整示例。
- 为后续真实教材适配留交接模板，记录教材类型、语言、扫描质量、章节异常、出题目标和必要的专属功能。
- 交付完成以用户能在本机走通目标流程为准，保存实际验证证据。

## 5. 并行分派与文件归属

建议采用一个集成负责人加三个执行智能体，每个执行者在独立 worktree 工作。

| 角色 | 负责内容 | 主要代码范围 | 协作要求 |
| --- | --- | --- | --- |
| A 集成负责人 | P00、P01、P02、P11、P12、P13 | storage、shared/types、main、preload、workers/service、公共配置 | 维护契约、迁移、共享接线与最终验收 |
| B 教材智能体 | P03、P04 | importer、anchors、OCR 模块、教材解析测试 | 向 A 提交接线需求，向 C 提交展示数据需求 |
| C 题库与界面智能体 | P05、P06、P09、P10 | practice、renderer、题库测试及交互测试 | 统一 UI 改动，消费 B 和 D 的明确接口 |
| D 本地生成智能体 | P07、P08 | 本地模型与生成任务模块、生成测试 | 提供服务接口及结构化草稿，向 A 提交公共接线需求 |

公共文件由 A 统一合并。其他智能体在各自分支实现必要改动时，须在交接中明确共享文件差异与依赖，集成时核对冲突。每个提交围绕一个可验收的工作包。

执行批次如下。

1. A 完成 P00、P01。B 可先检查样本策略，D 可先做硬件与本地模型可行性实测。
2. A 做 P02，B 做 P03、P04，D 做 P07。C 使用冻结样例开展 P05、P06，待 P02 合并后真实接通。
3. D 完成 P08，C 完成 P09、P10，A 集成共享接口并完成 P11。B 处理解析与来源定位缺陷。
4. A 主持 P12，B、C、D 修复各自缺陷，验收通过后 A 完成 P13。

## 7. 后续条件触发的扩展

以下任务根据新教材或用户使用反馈立项，分别具有独立验收范围。

- 新题型。多选、填空、简答、公式输入和案例组，分别定义答案结构、判分与历史记录兼容。
- 智能复习。基于真实复习反馈增加间隔重复与学习计划算法，并说明推荐依据。
- 学科工具。统计计算、运动处方练习、实验设计或其他交互模块，明确公式、单位、参数范围与验证样例。
- 更多文件格式。EPUB、Word、PPT 及音视频资料的导入、来源定位和版权适配说明。
- 跨教材综合学习。跨书检索、多来源出题、版本差异比较与知识点关系。
- 云端阶段。单独确认部署方式、账号需求、内容授权、资料同步、冲突处理、存储成本与访问控制后实施。

当前代码设计通过稳定 ID、版本化格式和清晰的数据访问接口支持后续扩展，工程量以当前离线流程为依据。
